# 진짜 고깃집 관리자 앱 (어머니용 설치 안내)

## 휴대폰으로 앱 받기

[**📱 진짜 고깃집 관리자 앱 다운로드 페이지 열기**](https://github.com/yunrang2/upload/releases/tag/realmeat-owner-v1.2.0)

1. 위 파란 글씨를 눌러 다운로드 페이지로 들어갑니다.
2. 화면을 조금 내려 **Assets** 아래 **Real_Meat_Owner_v1.2.0.apk**를 누릅니다.
3. **다운로드**를 누릅니다. (경고 문구가 나와도 가족에게 받은 파일이 맞는지 먼저 확인해 주세요.)
4. 다운로드가 끝나면 **열기**를 누릅니다.
5. 처음 설치하는 휴대폰이면 **이 출처의 앱 설치 허용** 안내가 나올 수 있습니다. 가족에게 받은 파일이 맞을 때만 허용하고 **설치**를 누릅니다.
6. 설치 완료 후 **열기**를 누르고 알림 요청이 나오면 **허용**을 누릅니다.

**유의:** 삼성 갤럭시의 자동 차단 설정 등 기종에 따라 문구가 달라질 수 있습니다. 설치 중 막히면 무리해서 다른 보안 설정을 변경하지 말고 가족에게 확인해 주세요.

## 배포 담당자용 (APK 이미 완성된 상태)

**앱을 새로 빌드할 필요가 없습니다.** 기존 GitHub Actions 빌드 두 건은 실패 기록이며 업로드된 완성 APK의 상태와는 별개입니다.

1. [GitHub 새 배포 만들기](https://github.com/yunrang2/upload/releases/new)를 엽니다.
2. **Choose a tag**에 `realmeat-owner-v1.2.0`을 입력해 새 태그로 만듭니다.
3. 제목: `진짜 고깃집 관리자 앱 1.2.0`
4. **Attach binaries** 영역에 본인이 갖고 있는 `Real_Meat_Owner_v1.2.0.apk`를 올립니다.
5. 설명에 위 한글 설치 순서를 넣고 **Publish release**를 누릅니다.
6. 배포 페이지에 **Real_Meat_Owner_v1.2.0.apk**가 표시되는지 확인한 다음에만 어머니께 링크를 전달합니다.

> **중요:** 이 글은 APK 업로드 완료를 뜻하지 않습니다. 배포 페이지가 열린 상태인지 반드시 확인해야 합니다.
