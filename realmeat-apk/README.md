# 진짜 고깃집 관리자 앱 (어머니용)

**안드로이드 휴대폰에서만 설치할 수 있습니다.** 아래 주소에서 `진짜고깃집_관리자_설치.apk`를 누르세요.

[⬇ 최신 앱 설치 파일 받기](https://github.com/yunrang2/upload/releases/tag/realmeat-owner-v1.1.0)

## 휴대폰에 설치하는 방법

1. 위의 **앱 설치 파일 받기**를 누릅니다.
2. 아래쪽의 **Assets(파일)** 목록에서 **진짜고깃집_관리자_설치.apk**를 누릅니다.
3. 다운로드 경고가 나오는 경우, 파일명이 맞는지 확인한 뒤 **다운로드**를 누릅니다.
4. 다운로드가 끝나면 **열기**를 누릅니다. 또는 **내 파일 → 다운로드**에서 APK 파일을 누릅니다.
5. 처음 설치할 때 **이 출처의 앱 설치 허용**이 나올 수 있습니다. 직접 받은 APK가 맞는지 확인한 뒤 허용합니다.
6. **설치**를 누르고, 완료되면 **열기**를 누릅니다.
7. **알림 허용**이 나오면 **허용**을 누릅니다.
8. **진짜 고깃집 관리자** 화면에서 사장님 인증을 마치면 됩니다.

> 삼성 갤럭시의 '자동 차단' 설정 등에 따라 외부 APK 설치가 막힐 수 있습니다. 설정을 변경하기 전 앱을 제공한 사람에게 확인해 주세요.

> 처음 배포된 시험용 앱입니다. 실제 예약 알림이 오는지는 설치 뒤 예약 테스트로 확인해야 합니다.

## 제작자용 안내

이 폴더는 APK 자동 빌드 소스(아이콘 포함)를 보관합니다. GitHub Actions의 `진짜 고깃집 관리자 APK 만들기` 워크플로가 빌드에 성공해야 위 다운로드 페이지에 APK가 나타납니다. 최신 앱 소스는 `source_v15.tar.gz.b64`이며, Firebase 서버 비밀 키는 포함되어 있지 않습니다.
